# Overlap and archival review

`commerce` is a French-language learning artifact for online-shop sales analysis with Pandas, NumPy, and Matplotlib.

It contains notebooks and a project PDF, rather than a maintained software application. The polished `python-retail` repository is the selected personal showcase for retail analytics because it adds reusable package code, tests, quality tooling, visual outputs, and a documented evolution roadmap.

## Proposed disposition

Archive `commerce` unless its historical or French-language learning value is explicitly retained. This review does not delete, archive, translate, or modify the original notebooks or PDF.

## Boundaries

- Treat the material as a course artifact, not an active product.
- Keep any future analysis modernization in `python-retail` unless a distinct purpose is approved.
- Owner approval is required before archive or deletion.
